## 🌌 What Is Odin’s Whisper?

**Valheim-Hack-v1** — internally nicknamed **Odin’s Whisper** — is an advanced gameplay enhancement suite built for players who have already conquered the tenth boss and now want to explore Valheim’s world with a different lens. Where the base game asks you to grind flint, tin, and silver for hours, this companion tool lets you shift the gears of fate: pulling damage, stamina, movement, and status mechanics into configurations that suit your personal saga.

Imagine the Allfather leaning over your shoulder, whispering options into your ear as you sail toward the Mistlands. That is the experience this project aims to deliver — a mod menu that feels like part of the world rather than a foreign overlay.

This README is intentionally exhaustive. It documents every module, every configuration flag, every design decision, and every FAQ we have collected during hundreds of hours of in-game testing.

## 🎮 Why This Project Exists

Valheim is a beautiful slow burn. But sometimes, after your fifth playthrough, the slow burn becomes a slow crawl. Odin’s Whisper exists for those players who have already *earned* their stripes and now want to write a different chapter — a chapter where the wind always blows favorably, where the mead never runs dry, and where the mountains part before you.

We do not view this as a shortcut. We view it as a **narrative tuning fork** — a way to conduct the rhythm of your own Viking epic.

## 🧠 Design Philosophy

1. **Stewardship, not domination.** The world stays Valheim. We only adjust the dials.
2. **Configurability over prescription.** Every feature is a toggle, never forced.
3. **Aesthetics matter.** The overlay is styled to match Valheim’s runic art direction.
4. **Support is sacred.** Every ticket receives a same-day response — usually sooner.
5. **Localization is respect.** Twelve language packs ship in the box, with community contributions welcome.

## 🛠️ Configuration Snapshot

All settings live in a single human-readable file named `odin_whisper.toml`. Below is an abbreviated example of what a typical configuration looks like:

    damage_multiplier = 3.5
    stamina_consumption = 0.0
    status_effects_enabled = false
    movement_speed = 1.8
    jump_height = 2.4
    ui_scale = "auto"
    language = "en"
    teleport_unlocked = true

Every value can be edited live through the overlay, so you never need to close the game to tweak your experience.

## 📚 Frequently Asked Questions

**Q: Does this work with multiplayer?**  
A: The mod is designed for solo play. Please respect other players’ worlds and use it only where you have permission.

**Q: Will this break my save?**  
A: Save compatibility has been maintained across every major Valheim patch since 2024. Backups are still recommended out of good habit.

**Q: Is the tool compatible with macOS?**  
A: Windows and Linux are the primary targets. macOS users report mixed results on M-series chips.

**Q: How do I request a new feature?**  
A: Open a GitHub issue using the “Enhancement Request” template. Our stewards triage weekly.

**Q: Where can I get help?**  
A: Our 24/7 customer support desk operates via the repository’s Discussions tab.
